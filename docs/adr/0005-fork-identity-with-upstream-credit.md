# Give the fork its own identity while retaining upstream credit

Status: accepted

The fork points GitHub and issue links to `gabbayron/tbc-new`, keeps visible links to the original project and MIT notice, and removes upstream Google Analytics tags. Download links still point to upstream releases until this fork publishes binaries. Reusing the upstream analytics or implying that the fork ships its own binaries would misrepresent ownership and availability. “WoW Sims” is temporary display text so branding can be replaced without altering simulator contracts.

See [the code index](../code-index.md#fork-identity-and-maintenance) for the relevant links and templates.
