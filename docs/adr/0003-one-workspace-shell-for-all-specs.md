# Use one workspace shell for all specs

Status: accepted

The desktop interface groups the existing Gear, Talents, and Rotation tabs under Build; Settings under Setup; and the existing detailed-results and Bulk tabs under Results and Batch. A narrow-screen select activates those same Bootstrap tabs rather than maintaining a second screen or router. This preserves each spec's working controls while giving all 17 routes one consistent navigation model. The trade-off is that the shared header must continue to recognize upstream tab identifiers when they change.

See [the code index](../code-index.md#redesigned-interface) for the shell and responsive styles.
